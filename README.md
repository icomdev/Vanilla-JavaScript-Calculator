# Vanilla JavaScript Calculator

Open `index.html` in a browser to use the calculator.

## Buttons

| Button | What it does |
| --- | --- |
| `0` | Adds 0 to the current number. |
| `1` | Adds 1 to the current number. |
| `2` | Adds 2 to the current number. |
| `3` | Adds 3 to the current number. |
| `4` | Adds 4 to the current number. |
| `5` | Adds 5 to the current number. |
| `6` | Adds 6 to the current number. |
| `7` | Adds 7 to the current number. |
| `8` | Adds 8 to the current number. |
| `9` | Adds 9 to the current number. |
| `.` | Adds a decimal point (one per number). |
| `+` | Adds the next number. |
| `-` | Subtracts the next number. |
| `*` | Multiplies by the next number. |
| `÷` | Divides by the next number. |
| `=` | Shows the result of the pending calculation. |
| `AC` | Clears both numbers and the selected operator. |
| `DEL` | Removes the last character of the current number (backspace). |

The clear button is labeled `AC`, not `C`. There are no `%`, `+/-`, or
separate backspace buttons; use `DEL` to delete a character.

## Keyboard

No calculator keyboard shortcuts are implemented, including Backspace.
Use Tab to focus a button and Enter or Space to activate it with the browser's
standard button controls.
