# Vanilla JavaScript Calculator

Open `index.html` in a browser to use the calculator.

## Buttons

| Button | What it does |
| --- | --- |
| `0` | Adds 0 to the current number. |
| `1` | Adds 1 to the current number. |
| `2` | Adds 2 to the current number. |
| `3` | Adds 3 to the current number. |
| `4` | Adds 4 to the current number. |
| `5` | Adds 5 to the current number. |
| `6` | Adds 6 to the current number. |
| `7` | Adds 7 to the current number. |
| `8` | Adds 8 to the current number. |
| `9` | Adds 9 to the current number. |
| `.` | Adds a decimal point; a second decimal point is ignored. |
| `+` | Adds the next number. |
| `-` | Subtracts the next number. |
| `*` | Multiplies by the next number. |
| `÷` | Divides by the next number. |
| `%` | Divides the current entry by 100; repeat to divide again. Empty entries are unchanged. Preserves pending operations (200 + 10 % = 200.1). |
| `=` | Shows the result. |
| `AC` | Clears both numbers and the selected operation. |
| `DEL` | Removes the last character from the current number. |

The clear button is labeled `AC`, not `C`. `DEL` handles deleting the last character.

## Keyboard

There are no calculator-specific keyboard shortcuts, including Backspace.
Use the buttons, or Tab to a button and press Enter or Space to activate it.
